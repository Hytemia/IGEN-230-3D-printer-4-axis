# 4-axis 3D printer based on design from Joshua Bird and Upcycles an Ender3 V2
### About
A prototype 4 axis 3D printer capable of printing large overhangs without supports. Layout based on design from Joshua Bird, but redesigned to reuse parts from Ender3 V2. With the aim to use as many parts of the Ender3 as possible. Slicing utilizes an edited version of S4 Slicer created by Joshua Bird.  

Github repo for UBC Intergrated Engineering 230 project team 2
This is a 4 month long capstone project for 2nd year Integrated Engineering Students at University of British Columbia
This repo is being updated intermittently with the goal of a complete build guide when finished
