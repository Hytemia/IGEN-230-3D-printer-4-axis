# 4-axis 3D printer based on design from Joshua Bird and Upcycles an Ender3 V2
### About
A prototype 4 axis 3D printer capable of printing large overhangs without supports. Layout and slicer are both derrived from design by Joshua Bird, Be sure to check out his original [4-axis Printer](https://github.com/jyjblrd/Core-R-Theta-4-Axis-Printer) and his [S4 Slicer](https://github.com/jyjblrd/S4_Slicer) 
This project is a redesign focusing on making the initial design more user friendly and accessible by adding features such as a heated bed and reusing parts from an Ender3 V2. With the aim to use as many parts of the Ender3 as possible to reduce costs.

Github repo for UBC Integrated Engineering 230 project team 2 consisting of 6 team members: Benjamin Chen, Daison Li, Lucie Li, Jenn Moon, Haruki Sakamaki, Alanna Yip
This is a 4 month long capstone project for 2nd year Integrated Engineering Students at University of British Columbia
This repo is being updated intermittently with the goal of a complete build guide when finished
